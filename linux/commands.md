# Linux Commands Practiced

| Command | Purpose |
|---|---|
| `pwd` | Show current directory |
| `ls` | List files |
| `cd` | Change directory |
| `mkdir` | Create a directory |
| `cp` | Copy files |
| `mv` | Move/rename files |
| `rm` | Remove files |
| `cat` | Display file contents |
| `grep` | Search text |
| `ip addr` | Display network interfaces |
| `ip route` | Display routing information |
| `whoami` | Show current user |
| `sudo` | Run an administrative command when permitted |

These commands are for learning and administration in the user's own lab.
