# Cybersecurity Home Lab

A beginner-friendly cybersecurity laboratory designed for safe, isolated practice using virtualization.

## Objective
Build an isolated environment for learning Linux, networking, defensive security, and security tooling without targeting systems that do not belong to the learner.

## Planned Lab
- Host operating system: Windows
- Virtualization: VirtualBox
- Security VM: Kali Linux
- Optional target VM: Windows/Linux test machine
- Network mode: Host-only or another intentionally isolated configuration

## Planned Activities
1. Install Kali Linux in VirtualBox.
2. Configure an isolated lab network.
3. Practice Linux command-line navigation.
4. Inspect network interfaces and local connectivity.
5. Learn basic packet/network concepts.
6. Practice defensive security tools against the user's own lab machines.
7. Document findings and lessons learned.

## Safety
All testing should be performed only on systems and networks you own or have explicit permission to test. Do not scan or attack public IP addresses, websites, or other people's devices.

## Evidence
Screenshots and results should be added after the lab is actually installed and exercises are completed.
